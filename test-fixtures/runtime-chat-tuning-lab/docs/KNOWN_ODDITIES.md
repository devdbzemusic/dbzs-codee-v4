# Known Oddities

- Support meldet, dass VIP-Bestellungen gelegentlich teurer werden.
- Die Runtime-Probe gibt bei Pfadproblemen oft zu grobe Fehlertexte zurueck.
- Legacy-Owner-Normalisierung darf nur bewusst angefasst werden.
- Review-Exports sollen keine `.codee`-Artefakte und keine versteckten Dateien einsammeln.
- Cache-Eintraege wachsen ueber laengere Sitzungen spuerbar an.
