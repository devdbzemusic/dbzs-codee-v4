# DBZS STYLEGUIDE

## Visual Identity

DBZS should feel:

- futuristic
- minimal
- fast
- intelligent
- immersive

## UI Principles

- dark-first interfaces
- neon-inspired hierarchy
- clean spacing
- modular layouts
- responsive workspaces

## Avoid

- cluttered dashboards
- enterprise-style forms
- oversized menus
- unnecessary animations

## Preferred Components

- detachable panels
- floating workspaces
- realtime status indicators
- contextual actions
- node-based workflows
