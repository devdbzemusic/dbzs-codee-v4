# Daily Use Readiness

## Persistenz

- [ ] Run überlebt Backend-Neustart.
- [ ] Run überlebt Electron-Neustart.
- [ ] offene Reviews bleiben erhalten.
- [ ] Host Actions werden nicht doppelt ausgeführt.

## Transparenz

- [ ] aktueller Step sichtbar.
- [ ] alle Tool Calls sichtbar.
- [ ] Dateiänderungen sichtbar.
- [ ] Commands und Exit Codes sichtbar.
- [ ] Fehler nicht verschluckt.

## Sicherheit

- [ ] kein Patch ohne Review.
- [ ] Restore Point vor Apply.
- [ ] Before-Hash geprüft.
- [ ] Commands aus Allowlist.
- [ ] Workspace Sandbox.
- [ ] Rollback getestet.

## Funktion

- [ ] Projektadapter erkannt.
- [ ] Plan erzeugt.
- [ ] relevante Dateien gelesen.
- [ ] Patch vorgeschlagen.
- [ ] Review durchgeführt.
- [ ] Patch angewendet.
- [ ] Tests real ausgeführt.
- [ ] Debug-Step bei Fehler.
- [ ] Abschlussbericht erzeugt.

## Stabilität

- [ ] drei erfolgreiche End-to-End-Runs.
- [ ] ein unterbrochener Run fortgesetzt.
- [ ] ein fehlerhafter Run kontrolliert beendet.
- [ ] keine manuelle DB-Reparatur nötig.
