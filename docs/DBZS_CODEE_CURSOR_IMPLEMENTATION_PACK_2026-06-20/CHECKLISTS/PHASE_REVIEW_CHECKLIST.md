# Phase Review Checklist

- [ ] Nur der angeforderte Scope wurde verändert.
- [ ] Bestehende Komponenten wurden geprüft und weiterverwendet.
- [ ] Keine zweite parallele State Machine eingeführt.
- [ ] Keine direkte Dateiänderung aus LLM-Output.
- [ ] Workspace Boundary Tests vorhanden.
- [ ] Fehlerpfade getestet.
- [ ] Migration additiv und idempotent.
- [ ] Neue Events dokumentiert.
- [ ] Keine Secrets in Logs.
- [ ] Typecheck ausgeführt.
- [ ] Tests ausgeführt.
- [ ] Build ausgeführt.
- [ ] Manuelle Tests ehrlich als RUN/NOT RUN markiert.
- [ ] HANDOVER/README nicht übertrieben.
- [ ] Bekannte Restpunkte aufgelistet.
